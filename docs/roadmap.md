# Roadmap

## Now
- **The architect for friends:** per-player access and limits, and `@architect` in plain chat.
- **Faster small builds:** a quicker model for simple requests, if the scenarios say quality holds.

## Next
- **Host it yourself:** a step-by-step guide for a small VPS with backups and a private link for the
  architect (the plan: [hosting.md](hosting.md)).
- **Bigger builds:** whole districts and cities, with roads, walls and plazas.
- **Terraforming:** rivers, hills, beaches and forests that blend into the land around them.

## Later
- **Better builders:** a self-critique round before "done", furnished room kits, richer palettes.
- **Redstone kits:** doors, elevators and farms, each tested live.
- **An in-game test bot** that checks previews and builds automatically.

## Done
- Paper + WorldEdit server in Docker, every download pinned and hash-checked.
- A building toolkit: parts, terrain, towns, renders, an audit, undo for everything.
- Eval suites for build quality and for the architect.
- The in-game architect: `/arc`, previews only you can see with a glowing frame, yes / no / undo.
- Survival travel: `/sethome`, `/home`, `/tpa`.
